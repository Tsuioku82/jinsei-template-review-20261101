# 人生の履歴書・見本の使い方

1. index.htmlを開き、男性用か女性用を選びます。配色は種類ごとの専用10色です。
2. 見本を開き、「デザイン・配色・文字の大きさを選ぶ」を押します。
3. デザイン・配色・文字（18/20/22px）を選べます。
4. 女性用は「キャラクターを選ぶ」で、小悪魔魔女・読書の魔女・花の魔女・なしを選べます。そばの見本と本文の画像が入れ替わります。
5. 選択はこのブラウザーに保存され、画面のURLにも残ります。デザインを変えても選択を引き継ぎます。127.0.0.1のリンクは同じPCで使うローカル版です。
6. 印刷は「この物語を印刷する」。暗い背景と装飾は印刷用に白黒へ切り替わります。

制作者向け：お客様の文章と写真はtemplateA/content/sample.jsonまたはtemplateB/content/sample.jsonの1箇所で管理し、node build.cjsで10案へ反映します。A07の3画像はdesignMediaにあります。実在の方の制作は専用フォルダと掲載確認を用意し、この架空の見本帳へ混ぜないでください。
